# Seu próprio CRM

**Utilize o seu próprio CRM. Pegue a base pronta aqui no portal Ruptura.**

Cada aluno usa uma instalação própria, com banco, login e dados independentes. Faça um fork de https://github.com/felipeferreira3d/crm-ruptura e siga o [guia de instalação](INSTALACAO.md) para conectar seu Supabase e publicar na sua Vercel.

Comece cadastrando um cliente e uma oportunidade. Depois organize projetos, prazos, propostas e recebimentos. Os dados começam vazios, para você preencher do seu jeito.

Em **Conta e equipe**, convide colegas pelo e-mail deles. Compartilhe o link gerado pelo canal que você preferir. Todos os membros têm acesso ao financeiro e aos demais registros daquele espaço; use um espaço separado se não quiser compartilhar tudo.

Para Google Calendar, o administrador precisa ativar a integração. Depois cada pessoa conecta sua própria conta. A exportação .ics funciona como alternativa manual.

Prospecção: cadastre ou importe perfis com mais de 200 mil seguidores. Varreduras diárias não estão ativas; a integração com fornecedor de dados ainda precisa ser conectada. Não há envio automático de mensagens.

Guarde backups pelo botão **Exportar dados** e use o canal de suporte do portal quando precisar.
